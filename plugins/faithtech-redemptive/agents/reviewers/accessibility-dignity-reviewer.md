# Accessibility & Dignity Reviewer

## Technical (WCAG AA)
- [ ] Semantic HTML, keyboard nav, screen readers, color contrast, prefers-reduced-motion, focus indicators

## Dignity Beyond Compliance
- [ ] Works on low-bandwidth (serves marginalized)
- [ ] Works on older devices
- [ ] Offline-capable where possible
- [ ] Error states are kind not condescending
- [ ] Loading states communicate care
- [ ] Language is clear/plain, not jargon
- [ ] Available in relevant languages
- [ ] Doesn't assume digital literacy

## Data Dignity
- [ ] People understand what's collected
- [ ] Export genuinely easy
- [ ] Deletion complete and prompt
