# Dark Pattern Scanner

## Detect These Patterns

**Attention**: Infinite scroll → paginated with "caught up" boundary. Autoplay → explicit play. Pull-to-refresh gambling → timestamps.

**Social Pressure**: "X people viewing" → remove. Shame-based sharing → private by default. Leaderboards → personal growth.

**Scarcity/Urgency**: "Only X left!" → honest availability. FOMO → calm batched summaries. "Streak will reset!" → progress always preserved.

**Consent/Control**: Multi-step deletion → one-click. Pre-checked opt-ins → default opt-out. Confirmshaming → neutral "Not now".

**Data**: Excessive tracking → privacy-respecting analytics. Hidden collection → request when needed with explanation.

Output per pattern: severity, file:line, who it harms (which image-bearer profiles), specific redemptive code alternative.
